## ✨ 这个客户端和别人做的有什么不一样

市面上的同类工具大多走两条路：要么只是把网页丢进一个浏览器窗口，连标题栏都是浏览器的；要么去抓番茄的正文接口，把小说抄到一个自建阅读器里。

这个项目选了第三条：**界面按桌面客户端的标准自己做，内容老老实实走官方网页版**。

- 自己画的标题栏：番茄图标、版本标识、置顶/护眼状态、窗口按钮，全部是应用自己的 UI，不再是浏览器外壳
- 网页在窗口里独立成层（Electron `WebContentsView`），标题栏和网页互不干扰，拖拽、双击最大化都是原生行为
- 不注入改写页面内容的脚本，不拦截广告，不绕过登录、会员和解锁机制

## 🚀 功能

- **自绘标题栏**：🍅 品牌区、状态标签（已置顶 / 护眼）、置顶、全屏、最近阅读、设置、最小化 / 最大化 / 关闭
- **置顶小窗**：`Ctrl + Shift + P` 一键置顶，边工作边看，标题栏会亮起"已置顶"
- **沉浸全屏**：`F11` 进全屏（标题栏自动让位给正文），`Esc` 退出
- **最近阅读**：自动记录打开过的书籍页（最多 12 条），从标题栏时钟图标一键回到上次那本
- **护眼模式**：给页面加一层暖色滤镜，夜里看着不刺眼
- **窗口记忆**：记住窗口大小与位置；显示器变了、窗口跑到屏幕外会自动归位
- **阅读缩放**：`Ctrl + =` / `Ctrl + -` / `Ctrl + 0`，也可以在设置里选 80% ~ 150%
- **托盘常驻**：最小化后从托盘点击图标即可唤回；托盘菜单含置顶、最近阅读、设置、退出
- **关闭到托盘**：可选开启，点 × 不退出程序
- **开机自启**：设置里一个开关，写进系统登录项
- **设置面板**：数据目录（可改盘、可打开）、缩放、护眼、置顶、关闭到托盘、开机自启、版本信息
- **单实例**：重复点图标只会把已开窗口拉到前面
- **断网友好**：加载失败给中文提示页，一键重试

## 📥 下载与安装

1. 到 [Releases](https://github.com/HYGH-MAX/fanqie-novel-desktop/releases/latest) 下载 `fanqie-novel-desktop-x.y.z-portable.exe`；
2. 放到一个单独的文件夹（例如 `D:\番茄小说\`），双击运行，免安装；
3. 首次运行若提示"Windows 已保护你的电脑"，点 **更多信息 → 仍要运行**（没有购买代码签名证书，属正常现象）；
4. 想要桌面图标：右键 exe → 发送到 → 桌面快捷方式。

> 想让它开机就在？设置面板里打开"开机自启"即可。

## 🗂️ 数据与缓存放在哪

默认在 `%APPDATA%\fanqie-novel-desktop`，里面是登录态（Cookie）、网页缓存、窗口记忆、最近阅读和设置。

**换盘**：标题栏齿轮 → 设置 → 数据目录 → "更改"，选一个新目录（例如 `E:\番茄小说数据`），程序会把新目录写进 exe 同级的 `config.json`，点"立即重启"后生效。换目录等于换一份登录态，所以最好在旧的目录还在时把 `Network`、`Local Storage` 等复制过去。

也可以直接在 exe 同级目录手写 `config.json`：

```json
{
  "dataDir": "E:\\番茄小说数据"
}
```

程序启动时会优先读这一项，其余设置（缩放、护眼、置顶、托盘、自启）都在设置面板里改，保存在数据目录的 `settings.json`。

## 🛠️ 自己编译

环境：Node.js 20+、Windows 10/11。

```bash
npm install
npm start          # 开发模式运行
npm run dist       # 打包便携版 exe，产物在 dist/
```

国内网络拉 Electron 慢的话，先设置镜像：

```bat
set ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/
set ELECTRON_BUILDER_BINARIES_MIRROR=https://npmmirror.com/mirrors/electron-builder-binaries/
```

## 🧱 代码结构

```
src/
  main.js        主进程：窗口、标题栏+网页双层布局、托盘、IPC、设置与最近阅读存储
  preload.js     contextBridge 暴露的窗口控制 / 设置 / 最近阅读接口
  shell.html     自绘标题栏（无边框窗口的顶端 40px）
  settings.html  设置面板
  recent.html    最近阅读列表
  icon.png       窗口与托盘图标
build/
  icon.ico       打包用图标（多尺寸）
  make-icon.ps1  图标生成脚本
```

安全设置：渲染进程 `nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`，网页与界面之间只通过白名单 IPC 通信。

## ❓ 常见问题

**需要登录吗？要钱吗？**
不登录也能看免费书；登录后书架和阅读进度与手机端同步。程序本身免费，不带第三方推广。

**为什么有的章节看不了 / 要会员？**
这是官方站自己的规则。本项目只是桌面外壳，不绕过官方任何限制。

**有广告吗？**
有，与官网一致。项目刻意不做广告拦截：拦截会破坏官方投放和作者收益，也容易导致页面异常。

**点 × 程序没退出？**
开了"关闭时最小化到托盘"。去托盘右键菜单选"退出"，或在设置里关掉这个开关。

**打不开、一直白屏？**
通常是网络或代理问题。程序会显示中文提示页，点"重新加载"；仍然不行换个网络（例如手机热点）试试。

**窗口位置乱了、跑到屏幕外？**
启动时会检查位置是否落在可见屏幕内，跑出去会自动回到默认位置。
